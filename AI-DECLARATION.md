## Scope of AI Usage

AI assistance was limited to the following activities:

* Concept clarification and code explanation
* Debugging suggestions
* Implementation planning
* Refactoring recommendations
* Documentation drafting
* Test idea generation

AI tools were **not used** to automatically generate final deliverables without human review.

Every task followed this workflow:

1. Human defines the problem
2. AI proposes an implementation plan
3. Team reviews and approves the plan
4. Human performs or approves execution
5. Output is validated and revised by the team
